# TP 01 : De la mesure à une décision sur l'énergie

##  Présentation du projet
Ce dépôt contient les travaux pratiques de Méthodes Numériques 2. 
L'objectif est d'auditer la consommation d'une pompe à l'aide de méthodes d'intégration numérique (méthode des trapèzes et méthode de Simpson) implémentées sous Scilab.
Nous avons utilisés des outils comme : YouTube, Google et l'IA pour les approfondissements

##  Structure du dépôt
 `TP_01_Application_Etudiant.sce` : script principal(application numérique, le cas de contrôle et l'analyse de la pompe).
`TP_01_Outils_Quadrature.sce` : fonctions de quadrature (trapèzes, Simpson, échantillonnage et calcul d'ordre).

## Exécution
1. Télécharger ou cloner le dépôt dans un même dossier.
2. Ouvrir Scilab et se placer dans le dossier.
3. Exécuter le script `TP_01_Application_Etudiant.sce`:les résultats s'affichent dans la console.
